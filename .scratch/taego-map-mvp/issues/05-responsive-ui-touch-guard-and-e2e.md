## What to build

건물 선택(`#3`), 고정 차량 레이어(`#4`), 개발 전용 Picker(`#5`)가 모두 구현된 상태에서, **PC·모바일 반응형 레이아웃, 모바일 드래그·핀치 오선택 방지 터치 가드, 그리고 프로덕션 격리까지 아우르는 전체 통합 E2E 검증**을 완성한다.

- **PC·모바일 반응형 카드 배치**:
  - PC 데스크톱 뷰포트: 선택된 지붕이 가려지지 않도록 컴팩트 플로팅 팝업/사이드 카드로 `Building Card`를 표시한다.
  - 모바일 뷰포트: 화면 하단 바텀 카드 형태로 표시해 상단 지붕을 계속 확인할 수 있게 하며, 지도가 화면 중심이 되도록 여백 UI를 최소화한다.
- **모바일 터치·핀치 제스처 가드**: 드래그(팬)나 두 손가락 핀치 줌 동작 시작(`movestart`/`zoomstart`)부터 종료 직후 쿨다운 구간 동안 실수로 `Roof Footprint`나 차량 마커가 열리지 않도록 차단한다.
- **전체 통합 회귀 테스트(Seam 2 & Seam 3)**: 샘플 지도 상태에서 건물 클릭, 차량 레이어 토글, 미등록 영역 안내 및 `Target Zone` 이동, 모바일 터치 가드, 프로덕션 빌드 격리를 E2E 테스트 스위트로 고정한다.

## Acceptance criteria

- [ ] PC 뷰포트(예: `1280×800`)에서 `Building Card`가 컴팩트 팝업/패널로 표시되고, 모바일 뷰포트(예: `390×844`)에서 하단 카드로 전환되며 닫기 및 지도 빈 곳 탭으로 닫힌다.
- [ ] **Seam 2 (모바일 터치) E2E 테스트**: 모바일 에뮬레이션 환경에서 등록된 건물 지붕 위에서 시작하는 드래그 이동이나 핀치 줌 제스처를 수행할 때 `Building Card`가 열리지 않는다.
- [ ] **Seam 2 (통합) E2E 테스트**: 건물 선택(`#3`) + 차량 레이어 ON/OFF(`#4`) + `Unregistered Area`에서 `Target Zone` 점프 버튼 동작이 서로 간섭 없이 함께 통과한다.
- [ ] **Seam 2 (정합성) E2E 테스트**: 줌 인/아웃, 이동, 뷰포트 리사이즈 후에도 `Roof Footprint`와 차량 마커가 지도 위 동일 지점에 고정되어 있다.
- [ ] **Seam 3 (최종 빌드 격리) E2E 테스트**: `next build` 후 `next start` 프로덕션 서버 환경에서 주요 사용자 시나리오가 모두 통과하고 Polygon Picker UI·코드에 접근할 수 없음을 검증한다.
